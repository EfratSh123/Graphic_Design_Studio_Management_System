#🎨 Graphic Design Studio Management System
A management tool built with C# / .NET WinForms and an integrated Access database, designed to streamline studio operations and reporting.


⚡ Overview

This desktop application helps manage projects, clients, and workflows in a graphic design studio.
It provides an intuitive interface for CRUD operations, reporting, and data management.

✨ Features

Add, edit, delete, and view projects, clients, and resources

Generate reports and track studio activities

User-friendly WinForms interface with structured workflows

Integrated Access database for data storage

Efficient data validation and error handling

🛠 Tech Stack
Component	Technologies
Frontend	C# / .NET WinForms
Database	Microsoft Access
Data Management	CRUD operations, reporting workflows
